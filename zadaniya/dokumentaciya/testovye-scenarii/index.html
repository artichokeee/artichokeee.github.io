Исходный файл (docx)

Тестовое задание для стажера на позицию «Тестировщик»

Основное задание:
Необходимо описать максимально возможное количество тестовых сценариев для проверки функционала «Запроса выписки из гос. реестра»(см. ниже).
Запрос выписки из гос. реестра
Сценарий запроса:
• Пользователь на панели инструментов выбирает действие «Получить выписку»
• Система отображает форму запроса выписки
• Пользователь указывает необходимые данные:
• юридическое лицо или индивидуальные предприниматель
• ИНН или ОГРН
• Нажимает "Получить выписку"
• Система посылает запрос
• Система ожидает получения выписки и отображает пользователю окно ожидания
• Система успешно получает выписку и отображает ее в форме запроса выписки
• Пользователь при необходимости:
• сохраняет выписку в файл
• отправляет выписку на печать
• Завершение сценария

Дополнительное задание:
• Описать негативные сценарии проверок функционала «Запроса выписки из гос. реестра» с учетом клиент-серверной реализации сервиса.
• Оценить трудозатраты по тестовым сценариям в условных временных единицах, сформировать список тестовых сценариев (на основе списка из основного задания) для случая сжатых сроков тестирования, когда тестировщик может выполнить не более 40% объема тестирования

Требования к присылаемым решениям:
Допустимо предоставление результатов в любом удобном для соискателя формате. Например, в виде таблицы:
Проверка
Ожидаемый результат
Нажатие кнопки «Проверить подпись» для корректной записи
Успех(если подпись корректна)
Нажатие кнопки «Проверить подпись» для искаженной записи
Неуспех(если проверка подписи не прошла)
Нажатие кнопки «Печать»
Открывается окно печати.
…

Максимальное время на выполнение задания: 2 недели
