Чек-лист + кейсы

Тестовое задание для тестировщика из открытой коллекции на GitHub. Тема: Тестовая документация. Решение можно положить в портфолио.

Исходный файл задания (txt)

Существует игровая платформа, предоставляющая клиентам площадку для размещения их игр. В игры можно играть на деньги (только авторизованным пользователем) и в демо-режиме. В команду разработки поступило ТЗ на интеграцию новой игры в платформу.
Необходимо:
1. Составить чек-лист для тестирования доработки.
2. Описать в развернутом виде по одному позитивному и негативному сценарию с заполнением всех необходимых полей.

Требование001
Необходимо добавить на платформу новую игру провайдера.
Провайдер: Microgaming
Игра: Goldaur Guardians
Game id: goldaurGuardiansDesktop, goldaurGuardians
Наличие джекпота – да
Тип игры – слот
Раздел: новинки
Ограничения по гео, если есть – недоступна в РФ
Валюта: USD, EUR
