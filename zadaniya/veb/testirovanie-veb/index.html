Тестирование веб

Тестовое задание для тестировщика из открытой коллекции на GitHub. Тема: Веб-тестирование. Решение можно положить в портфолио.

Исходный файл задания (txt)

Сайт: https://frutonyanya.ru/
1.Составить чек-лист тестирования регистрации на сайте.
2.Вам поступила задача «Пользователь не смог авторизоваться на сайте, проверить корректность работы авторизации». Какие данные вам необходимы для проверки ситуации? Как вы будете выполнять эту задачу?
3.Распишите любой сценарий поведения пользователя в виде тест-кейса.
