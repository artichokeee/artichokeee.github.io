Задание 3
Третье задание разделено на уровни, их необходимо выполнять по
очереди, но не обязательно выполнять все.
Level 1. На странице https://www.ivi.ru/profile имеется блок, содержащий
информацию о состоянии баланса пользователя.
Необходимо найти запросы к API, из которых мы получаем данные для заполнения
этого блока и сопоставить их с отображаемыми на странице данными. Ожидается
отчет в виде скриншотов с сопоставлением данных и комментарий о найденных
запросах.
Level 2. Используя программу Fiddler/Charles изменить баланс пользователя на
5000 долларов США. Ожидается отчет в виде скриншотов/видео с процессом
замены данных и конечным результатом. Подмена данных руками в html не
считается выполненным заданием.
Level 3. Выполнить Level 2 в приложении Иви на iOS/Android Ожидается отчет в
виде скриншотов/видео с процессом замены данных и конечным результатом
(скриншоты приложения).
