Тестовое задание на ручное тестирование:

1.
Подготовить таблицу в excel для хранения тестовых данных
Написать несколько тестовых кейсов на форму авторизации Yandex
Написать несколько тестовых кейсов на форму регистрации Yandex
Результат: описанные в таблице тест-кейсы
Критерии проверки: проверяющий может воспроизвести все шаги из тест-кейсов.

2.
Подготовить GET, POST и PUT запросы для любого реального сервиса. Под реальным сервисом
имеется ввиду реально работающий веб-сервис (например, интернет магазин)
Запросы должны быть выполнены в POSTMAN.
Как минимум один запрос должен содержать токен авторизации
Результат: файл коллекции POSTMAN
Критерии проверки: проверяющий воспроизвести запросы, не совершая дополнительных действий,
кроме как открыть присланную коллекцию и выполнить эти запросы.

3.
Перейти на сайт hps://www.w3schools.com/sql/trysql.asp?ﬁlename=trysql_asc
Найти таблицы базы данных и написать запросы, которые
- выбирают заказы с id сотрудника = 4
- выбирают все продукты, где в единице измерений присутствует "box"
Результат: два запроса в базу.
Критерии проверки: проверяющий может выполнить эти запросы на указанном выше сайте и
получить ожидаемый выше результат.

4.
Провести исследовательское тестирование портала hps://dasreda.ru/
Результат: в таблицу из п.1 необходимо занести хотя бы один найденный баг (чем больше, тем
лучше).
Критерии проверки: ориентируясь на описание багов, проверяющий может их воспроизвести по
шагам.

5.
Перейти на hps://www.cdek.ru/
Нажать на кнопку "Рассчитать"
Ввести название города Москва
Результат: скриншоты респонса запроса, который возвращает список городов
Критерии проверки: респонс на скриншоте соответствует респонсу по введенному наименованию
город.
